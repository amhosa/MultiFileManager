# MultiFileManager

**Fast and powerful Windows file manager with multi-file copy, cut, search, preview, and more.**

MultiFileManager is a Windows desktop file management application designed for working with files and folders efficiently and conveniently.

## Features

* Copy files to multiple destinations
* Cut and move files to destinations
* Undo / Redo file operations
* Delete and restore files
* Rename files and folders
* Create new folders
* Search files and folders
* File and folder preview
* Favorites and recent locations
* Windows desktop interface
* 3-day trial period
* License activation system

## Download

Download the latest installer from the **Releases** section:

**MultiFileManager-Setup.exe**

## Trial Version

MultiFileManager includes a **3-day trial period (72 hours)**.

After the trial period expires, file-changing operations are disabled. The application itself remains available so that the user can enter a valid license and activate the full version.

Uninstalling and reinstalling the application does not normally reset the trial period.

## License

A valid license code is required to use the full version after the trial period.

To activate the application:

1. Open **Activate App** from the application menu.
2. Enter your license code.
3. Click **Activate**.

## System Requirements

* Windows 10 or later
* x64 system

## Privacy

MultiFileManager does not require an online connection for its normal file management features.

## Support

For support, licensing, and purchase information, please use the contact information provided by the developer.

# MultiFileManager — فارسی

**مدیریت سریع و قدرتمند فایل‌ها در ویندوز**

MultiFileManager یک برنامه دسکتاپ ویندوزی برای مدیریت آسان و سریع فایل‌ها و پوشه‌ها است.

## امکانات

* کپی فایل‌ها به چند مقصد
* انتقال و Cut فایل‌ها
* Undo / Redo عملیات فایل
* حذف و بازیابی فایل‌ها
* تغییر نام فایل و پوشه
* ایجاد پوشه جدید
* جستجوی فایل و پوشه
* پیش‌نمایش فایل‌ها و پوشه‌ها
* مدیریت Favorites و مسیرهای اخیر
* محیط گرافیکی ویندوز
* نسخه آزمایشی ۳ روزه
* سیستم فعال‌سازی با کد لایسنس

## دانلود

آخرین نسخه برنامه از بخش **Releases** قابل دریافت است:

**MultiFileManager-Setup.exe**

## نسخه آزمایشی

MultiFileManager دارای **نسخه آزمایشی ۳ روزه (۷۲ ساعت)** است.

پس از پایان دوره آزمایشی، عملیات مربوط به تغییر فایل‌ها غیرفعال می‌شوند؛ اما خود برنامه بسته نمی‌شود و کاربر می‌تواند با وارد کردن کد لایسنس معتبر، نسخه کامل را فعال کند.

حذف و نصب مجدد معمولی برنامه باعث شروع مجدد دوره آزمایشی نمی‌شود.

## فعال‌سازی

پس از خرید لایسنس:

1. از منوی برنامه **Activate App** را باز کنید.
2. کد لایسنس را وارد کنید.
3. روی **Activate** کلیک کنید.

## نیازمندی‌های سیستم

* Windows 10 یا بالاتر
* سیستم 64 بیتی

## حریم خصوصی

برای استفاده عادی از امکانات مدیریت فایل، اتصال دائمی به اینترنت لازم نیست.
